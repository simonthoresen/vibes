# 🚀 QUICK START CARD

**Wizard Terrain Modifier** - Multiplayer 3D Game

---

## ⚡ 5-Minute Setup

```bash
# 1. Install Node.js (if needed)
# Download: https://nodejs.org/

# 2. Install dependencies
npm install

# 3. Start server
node server.js

# 4. Open game
# Browser: Open index.html
# URL: http://localhost:8080
```

---

## 🎮 Play Instructions

| Action | How |
|--------|-----|
| **Move** | WASD keys |
| **Jump** | Spacebar |
| **Cast Spell** | Press 1, 2, 3... 0 (for spells 1-10) |
| **Rotate Camera** | Right-click + drag mouse |
| **Zoom** | Scroll wheel |
| **Pause** | ESC key |

---

## 🎯 10 Spells

1. **Raise Terrain** - Lift ground up
2. **Lower Terrain** - Dig downward
3. **Level Terrain** - Flatten area
4. **Smooth Terrain** - Reduce jagged edges
5. **Fireball** - Explosive blast
6. **Lightning** - Electric strike
7. **Tornado** - Spinning vortex
8. **Meteor** - Falling projectile
9. **Water Source** - Create water
10. **Time Warp** - Slow effect

## 👥 Multiplayer

**Host Game:**

**Join Game:**
- Click "Join Game"
- Enter: `localhost:8080`
- Enter your name

## 📊 Performance

- **FPS Target**: 60 (mid-range GPU)
- **Memory**: ~150MB per player
- **Islands**: 64x64 to 512x512 sizes
- **Players**: 4-8 per server
- **Network**: Real-time WebSocket

---

## 🐛 Troubleshooting

**Server won't start:**
- Install Node.js
- Run `npm install`

**Game won't load:**
- Hard refresh browser (Ctrl+Shift+R)
- Check server running

**Low FPS:**
- Reduce island size
- Lower graphics quality
